# Reegha Marwah Website

This repository contains a simple static website for Dr. Reegha Marwah, built as a one-page portfolio and contact site.

## Included
- Intro / hero section
- About section with placeholder bio
- Services overview
- Gallery with placeholder photographs
- WhatsApp, Practo, and Google profile contact links
- Responsive, mobile-friendly layout
- GitHub Pages deployment workflow

## Files
- `index.html` — page structure
- `styles.css` — styling and responsive design
- `script.js` — small enhancement script
- `.github/workflows/deploy-pages.yml` — automatic GitHub Pages deployment

## Customizing the site
Update the following content in `index.html`:
- Bio text
- Services
- Testimonials
- Contact links
- Gallery images

## Enabling GitHub Pages
After pushing to GitHub, go to:
1. Repository Settings
2. Pages
3. Source: GitHub Actions

Then the workflow will publish the site automatically.

## Notes
The current bio and images are placeholders and meant to be replaced with your final clinic details and patient photos.
